# Amigo Secreto

![Banner](assets/amigo-secreto.png)

> Una aplicación interactiva para organizar sorteos de Amigo Secreto.

---

## 📌 Descripción

Este proyecto implementa una aplicación web simple para gestionar sorteos de Amigo Secreto. Los usuarios pueden agregar nombres de amigos, visualizar la lista de participantes y realizar sorteos aleatorios para seleccionar un amigo secreto.

---

## 🛠️ Funcionalidades

- **Agregar Nombres**: Los usuarios pueden ingresar nombres de amigos en un campo de texto y añadirlos a una lista.
- **Validación de Entradas**: Se validan los nombres para evitar campos vacíos, nombres duplicados y caracteres no permitidos (como números).
- **Visualización de la Lista**: Los nombres agregados se muestran en una lista debajo del campo de entrada.
- **Sorteo Aleatorio**: Al hacer clic en el botón "Sortear Amigo", se selecciona un nombre aleatorio de la lista y se muestra en la interfaz.
- **Interacción Mejorada**: Los nombres se pueden agregar presionando la tecla **Enter** o haciendo clic en el botón "Añadir".

---

## 🚀 Tecnologías Utilizadas

- **HTML**: Estructura básica de la aplicación.
- **CSS**: Estilos para mejorar la apariencia visual.
- **JavaScript**: Lógica para agregar nombres, validar entradas y realizar sorteos.
- **GitHub**: Repositorio para almacenar y compartir el código.

---

## 📋 Requisitos

Para ejecutar este proyecto localmente, no necesitas instalaciones adicionales. Simplemente abre el archivo `index.html` en tu navegador.
